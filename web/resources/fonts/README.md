# Font sources

Downloaded from the official repositories at the pinned revisions below.
Subset with fontTools to the Latin and Latin Extended unicode ranges in
`../../styles/fonts.css`, retaining OpenType layout features and variable axes.
Bricolage exceeded 110 KB, so its width axis was frozen at 100; weight and
optical size remain variable. No CJK glyphs are included.
Each family has its original SIL OFL 1.1 license alongside its font.

- Geist: https://github.com/vercel/geist-font/blob/ef2597cfc42f4797676df105517ccc0a1cfa6569/fonts/Geist/variable/Geist%5Bwght%5D.ttf
- GeistMono: https://github.com/vercel/geist-font/blob/ef2597cfc42f4797676df105517ccc0a1cfa6569/fonts/GeistMono/variable/GeistMono%5Bwght%5D.ttf
- BricolageGrotesque: https://github.com/ateliertriay/bricolage/blob/84745e5b96261ae5f8c6c856e262fe78d1d6efdd/fonts/variable/BricolageGrotesque%5Bopsz%2Cwdth%2Cwght%5D.ttf
